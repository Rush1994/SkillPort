# 开发路线

本项目目前是开发预览。当前可用行为见[使用指南](usage.md)，下列未完成项不应出现在可用功能声明中。

## 当前能力

已实现单目录 push/pull、标签和制品查询、仓库配置、Docker 凭据复用、自动协议识别、基本校验、来源基线、离线 status、目录锁及干净更新备份。

已有本地单元测试、模拟 Registry/凭据助手测试和 Windows 独立程序往返测试；指定真实 Registry 上验证过下载、编辑、重传及 Desktop helper 调用。其他平台的交叉编译不代替原生验收，也不代表所有 Harbor 版本和认证方式已通过。

## 校验完善

- [ ] YAML 详细行列、规则编号、实际值/阈值和修复建议；有界 alias 支持。
- [ ] 本地 Markdown 资源链接检查：缺失或被排除时报警，越界时报错，不访问网络链接。
- [ ] 精确敏感路径/规则例外，单独显示 allowed；不得提供通用关闭检测的 force。
- [ ] 完善疑似命中、未扫描状态和 strict 行为；输出与 diff 均脱敏。
- [ ] 可配置大小/条目/深度限额，拒绝零、负数、溢出和无效单位，测试恰好达限与超限。

## 同步语义

- [ ] 可变标签：仅同源标签仍等于基线时允许更新，远端变化或删除时停止；服务器不可变策略优先。
- [ ] 离线文本 diff：UTF-8 有界行差异，默认每文件 1 MiB；二进制和超限文件只显示摘要，敏感内容隐藏。
- [ ] 远端 status/diff：区分本地变化、远端变化、双方变化、引用不存在和查询失败，未知不能显示已同步。
- [ ] 同源 `pull --overwrite-local`：完整备份成功后才覆盖；不能用于覆盖未跟踪或其他来源目录。
- [ ] 可恢复的内容和记录共同提交；中断、文件占用、重命名、备份失败和恢复失败的故障注入。
- [ ] 发布成功但本地记录失败的可恢复工作流；不重复误报上传失败。

保留不提供 push --force 的原则。需要严格并发保护时使用唯一标签和 Harbor 不可变规则，不声称客户端预检查具有事务性。

## 批量与远端浏览

- [ ] Harbor API 分页列出项目仓库和可识别 Skill 制品，使用有界并发；无列表权限不妨碍已知引用同步。
- [ ] tags 同时返回 digest；支持与 Registry API 分开的 Harbor API 认证验收。
- [ ] 批量 push 仅发现直属 Skill 子目录；所有候选预检通过后才上传。
- [ ] 批量 pull 指定标签时下载远端候选；不指定标签时只更新已有本地跟踪目录。
- [ ] 批量逐项提交，运行期失败默认停止，可 continue-on-error；有失败整体返回非零并保留每项状态。

不因为远端列表缺少某个 Skill 就删除本地目录，不宣称跨仓库事务。

## 连接和发布准备

- [ ] 临时网络错误有界重试，不重试认证和参数错误；完善 token 服务的独立端点策略。
- [ ] 完善 Docker 旧式认证键兼容及诊断；保持精确主机/端口隔离。
- [ ] 建立发行版本并发布变更日志。
- [ ] 打包 Windows amd64、Linux amd64/arm64、macOS arm64，提供校验值、LICENSE 和所需第三方声明。
- [ ] 为公开仓库配置私密漏洞报告渠道；不填写虚构邮箱或响应承诺。

## 首个稳定版本的验收门槛

| 类别 | 必须覆盖 |
|---|---|
| 连接 | HTTP、HTTPS、CA、自动探测、显式策略、取消及错误分类 |
| 认证 | 真实 auths/credsStore/credHelpers、身份令牌、拒绝/无权限/助手异常、无秘密输出 |
| 同步 | 新标签、同标签冲突、远端删除、双方修改、备份失败、基线篡改、并发锁 |
| 数据 | UTF-8/BOM/CRLF、中文空格路径、恶意归档、链接、大小边界、哈希不符、解压膨胀 |
| 批量 | 全量预检、运行期部分失败、分页、不隐式删除本地 Skill |
| 脚本 | JSON、退出码、无 TTY、dry-run 不发布，失败不会被标为已同步 |
| 平台 | Windows 10/11/Server 2022，PowerShell 5.1/7 和 CMD；Linux/macOS 原生验证 |
| 服务 | 记录 Harbor 版本、操作系统和认证方式，实际验证项目权限及标签不可变策略 |

模拟测试、真实服务测试、原生运行和交叉编译结果分开报告。缺少真实环境时可继续实现和本地验证，不能宣称完整验收通过。

## 范围边界

不加入 Agent 平台接入、Skill 执行、环境依赖检查、运行时管理、项目依赖管理、Web 市场或服务端。暂不实现自动合并、远端删除或独立登录凭据管理。离线导入导出、签名、其他 Registry 和旧制品兼容按后续实际需求评估。
